# Harvey — Autonomous AI Sales Agent

Harvey is an autonomous sales agent that runs locally. It finds target companies matching your ideal customer profile (ICP), discovers verified decision-maker contacts, writes concise personalized cold emails using proven sales frameworks, coordinates delivery, handles incoming replies, and schedules meetings.

Repository: `https://github.com/ethanplusai/harvey`  
Location: `.agents/skills/harvey/`

---

## Capabilities & Sub-Agents

Harvey orchestrates 5 specialized sub-agents:

1. **Scout (Prospecting & Enrichment)**:
   - Queries web search engines (DuckDuckGo, Bing, Google, Serper) for companies matching ICP criteria.
   - Learns corporate email patterns (from site mailto links or Hunter domain search) and verifies deliverability (via Reoon, ZeroBounce, Hunter, or SMTP) before marking emails valid.
   - Collects buying signals: tech stack detection (~35 technologies like HubSpot, Shopify, Intercom), active hiring signals from career pages or job boards (via `python-jobspy`), and SERP ranking signals.

2. **Writer (Personalized Copywriting)**:
   - Generates tight, anti-slop 3-email cold sequences tailored to the company's verified signals.
   - Strict constraints: Email 1 (<75 words), Email 2 (<75 words), Email 3 (<40 words). Zero AI boilerplate, zero filler questions, and no tracking pixels.

3. **Sender (Campaign & Outbox Execution)**:
   - Supports native Google Workspace / Gmail OAuth, SMTP/IMAP (Fastmail, AgentMail), or Instantly.
   - Paces delivery with human jitter, quiet hours, daily quotas, stop-on-reply, and optional manual outbox approval.

4. **Handler (Reply & Conversation Management)**:
   - Monitors inboxes for replies, dedups messages, and classifies prospect intent (Meeting Requested, Information Requested, Objection, Not Interested, Out of Office, Bounce).
   - Automatically handles bounces (marks address invalid, cancels pending sends, enforces bounce rate limits).

5. **Analyst (Pipeline Analytics)**:
   - Runs during idle cycles to analyze conversion rates, pipeline velocity, top-performing signals, and cohort engagement.

## Setup & CLI Quickstart

### 1. Environment & Dependencies

From the project root or `.agents/skills/harvey/`:

```bash
# Create virtual environment and install Harvey
cd .agents/skills/harvey
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\Activate.ps1
pip install -e .

# Install browser for web crawling / LinkedIn (optional)
python -m playwright install chromium
```

### 2. Configure Providers (`.env`)

Create `.agents/skills/harvey/.env` from `.env.example`:

```bash
# Email sending: Choose Gmail OAuth, SMTP, or Instantly
GMAIL_CLIENT_ID=
GMAIL_CLIENT_SECRET=
# or SMTP
SMTP_HOST=
SMTP_PORT=587
SMTP_USERNAME=
SMTP_PASSWORD=

# Email verification (Reoon, ZeroBounce, or Hunter)
REOON_API_KEY=
ZEROBOUNCE_API_KEY=
HUNTER_API_KEY=

# Discovery (optional)
DATAFORSEO_LOGIN=
DATAFORSEO_PASSWORD=
SERPER_API_KEY=
```

### 3. Product Training

Train Harvey on any product or landing page URL:

```bash
harvey train https://example.com
```
This automatically extracts value propositions, ICP boundaries, and competitive wedges, populating `harvey.yaml`, `skills/product_knowledge.md`, and `skills/competitive_intel.md`.

### 4. Key CLI Commands

- `harvey setup`: Interactive wizard to configure ICP, channels, and behavior.
- `harvey signals`: Review proposed buying signals and confirm active ones (`harvey signals --confirm free`).
- `harvey discover`: Estimate and run lead discovery across target sectors and locations.
- `harvey run`: Start the autonomous heartbeat loop (prospecting, sequence generation, delivery, reply triage).
- `harvey dashboard`: Launch the local management console on `http://localhost:5555`.
- `harvey outbox`: Inspect, approve, or reject staged emails waiting in review.
- `harvey export`: Export verified prospect and company cohorts to CSV.
- `harvey usage`: View exact Claude / LLM token consumption and subscription quota utilization.
